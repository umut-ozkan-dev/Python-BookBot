# Python-BookBot
A Python program used to analyze the contents of the novels and books.

### Contents
The CLI Python-BookBot program inputs the location of a book in a text format and outputs word count, character count and estimated time to read the book.
Usage:
```

python3 main.py <path_to_book>

```
